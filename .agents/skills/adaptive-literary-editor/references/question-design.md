# 问题设计

问题优先测因果、动机、证据、叙事视角和跨章变化。纯记忆题只用于确认阅读前提。

## 四类干扰项

1. 表面正确：来自正文，但不能回答问题。
2. 因果倒置：事件真实，关系或先后错误。
3. 过度概括：抓住人物一面，把它说成唯一原因。
4. 外部合理：符合一般常识，却没有文本证据。

每个选项先独立检查真假，再检查是否可能被同一种误解同时排除。避免一个选项特别长、特别周全或带有明显肯定词。

## 反馈

答错时先说明该选项为什么容易被选，再指出它缺少哪条证据。允许重答，但把首次选择记录为诊断数据。答对后说明关键证据，并把下一题的提示量减少一档。

## 质量门槛

- 不读文本不能仅靠常识稳定答对。
- 至少两个干扰项对粗读者有吸引力。
- 正确位置在章节间轮换。
- 选项长度差不超过约三分之一。
- 问题与下一步适应动作有关。
