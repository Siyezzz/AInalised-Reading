# 自适应文学编辑

这是一套跨书复用的方法，不保存某一本书的专用写法。

拿到新书后，先按 [作品研究流程](references/research-pipeline.md) 建立可追溯的作品档案，再决定怎样讲。人物做了什么、事件先后和后果不能为了有趣而改变。人物动机和主题解释要区分文本事实、主流解释与争议观点。每章保留一处通往原著的入口。

## 写作

根据作品的文体特征和读者当前最需要的帮助选择一种主策略。不要把所有书改成同一种平台腔，也不要同时堆叠所有策略。

- 需要读懂时，减少从句和抽象判断，把因果写在动作之后。
- 需要兴趣时，从人物当下的难题切入，不虚构新冲突。
- 需要提高时，保留原著词语、叙述空白和不完全确定性，让读者自己判断。
- 需要应试时，把人物、情节与证据融进正文，不写成教辅讲义。
- 原作依靠讽刺、叙述视角、重复、节奏或留白产生效果时，改写必须保留对应功能。词句可以变化，文学作用不能无故消失。

正文像一个熟悉作品的编辑在讲故事。少用冒号、长破折号、成串标签和“真正重要的是”一类提示语。能用动作表现的，不先下结论。参照 [写作模式](references/style-modes.md) 和 [通用文学方法](references/literary-methods.md)。

## 出题

问题应诊断理解，而不是检查读者有没有记住刚出现的一句话。每题四个选项。正确项和干扰项在长度、语气与具体程度上保持接近，正确位置要变化。

干扰项必须各自对应一种真实误解，如只看表面行为、混淆因果、把读者常识当成文中证据、把局部事实夸大成全部原因。提交后分别解释所选答案，不只公布正确项。参照 [问题设计](references/question-design.md)。

## 自适应

把一次反馈用于下一段或下一章，不追溯篡改已经读过的内容。

- 没看懂：下一段显化人物关系与因果，题目保留一次证据提示。
- 太简单：下一段减少解释，增加原文与需要推断的空白。
- 太长：下一段压缩背景，保留转折和关键动作。
- 答错：记录误解类型，下一题换情境再测同一能力。
- 连续答对：减少提示，转向跨段或跨章比较。

不要只优化点击与停留。优先保持事实准确、理解提升、作品差异和逐步接近原著。完成一个项目后只沉淀可迁移的方法，不把单书结论写回本技能。
