# 知己读书

> 一本会读懂你的书。

**知己读书** 是一个会随着你的阅读而不断进化的个性化阅读平台。它不满足于把名著原封不动地摆在你面前，而是为每一位读者，重新讲述每一个故事。

## 它是什么

把一部经典名著交到你手上之前，知己读书会先问自己一个问题：**「眼前的这位读者，需要怎样的讲述？」**

于是它会为你：

- **重写每一章** —— 用你熟悉的语言、你习惯的节奏，把原作重新讲一遍；
- **随你而变** —— 你的每一次选择、每一个偏好，都会成为它下一次讲述的依据；
- **定制你的阅读路径** —— 从书目到章节，从难度到讲法，都围绕你一个人展开；
- **陪你读懂** —— 边读边提问、边思考，让「读过」真正变成「读懂」。

这不是一本电子书，而是一位随叫随到、越读越懂你的私人导读。

## 即刻开始

打开 [知己读书](https://zhiji-reading.li-siye-0123.workers.dev/)，即可开始你的第一段阅读。

- **无需安装，无需配置** —— 一个链接，随处可读；
- **用邮箱注册一个账号** —— 登录一次，之后 30 天内无需重复登录，换设备也能接着读；
- **书架与进度自动保存** —— 读到哪里，记到哪里。

## 它是如何读懂你的

每一次阅读，知己读书都在倾听：

- 你选择了什么书，又在哪里停下；
- 你喜欢怎样的讲法，又在哪里困惑；
- 你给出的每一个回答，都是它理解你的线索。

这些信号汇聚成一份只属于你的「阅读画像」，并反过来塑造下一次讲述。**你读得越多，它讲得越像你。**

## 私密与自主

你的书架、你的进度、你的阅读画像，只属于你自己。每位读者接入自己信赖的 AI 服务，让阅读体验完全由你把控。
